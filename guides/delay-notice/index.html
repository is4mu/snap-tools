納期が遅れそうなときの連絡文

結論

納期遅延の連絡で相手が困るのは、「遅れます」だけで終わる文面です。事実・影響・次の提案・お願いの4点を短く入れ、代替案を必ず1つ添えます。長い謝罪文は不要です。遅れると分かった時点で送る型を覚えれば、7分程度で文面が組み立てられます。定期の進捗報告は 進捗連絡テンプレート を、日数の見直しは 作業日数とバッファの見積もり方 を参照してください。

送るタイミング（手遅れになる前）

「たぶん間に合う」と思い始めた時点が送るタイミングです。納期当日や前日は手遅れになりやすいです。目安として、当初の納期まで残り3営業日以上あるうちに、遅延の可能性を共有します。素材未着・仕様変更・体調不良など、原因の種類に関わらず「影響が出ている」時点で動きます。

文に入れる要素（事実・影響・案・お願い）

  1. 事実 … 何が起きたか（箇条書き1〜2行）
  2. 影響 … 当初納期に対してどう変わるか
  3. 案 … 日程をずらす／範囲を絞る／段階納品のいずれかを1つ提示
  4. お願い … 先方の判断が必要な点を1つに絞る

原因の詳細説明は、相手の判断に必要な範囲までに留めます。内部の作業ログ全文は不要です。

文例（メール／チャット短文）

メール向け（やや丁寧）

件名: 【ご相談】〇〇案件の納期について

〇〇様

お世話になっております。△△です。
進捗共有です。〇〇の確認待ちが想定より長く、当初の〇月〇日納品は難しい見込みです。

【影響】全体納品が2〜3営業日遅れる可能性があります。
【ご提案】トップページのみ〇月〇日に先に納品し、下層は〇月〇日に納品する段階案です。
【お願い】上記案で進めてよいか、ご判断をいただけますと幸いです。

別案がご希望であればお知らせください。

チャット向け（短文）

〇〇案件の進捗です。確認待ちの影響で、当初納期（〇/〇）は2〜3営業日遅れる見込みです。
案：トップ先納品（〇/〇）＋下層後日（〇/〇）で進めたいです。ご希望があれば教えてください。

失敗例

納期当日に「申し訳ありません、間に合いませんでした」とだけ送り、代替日程や範囲の提案がないパターンです。相手は社内調整ができず、信用だけが下がります。もう一つの失敗は、原因説明が長文で、何を決めてほしいのかが文末に埋もれていることです。

手順まとめ

  1. 遅延の可能性を認識したら、まず影響日数をざっくり見積もる
  2. 代替案を1つ（日程・範囲・段階納品）用意する
  3. 事実・影響・案・お願いの順で短く書く
  4. 進捗連絡テンプレート の「遅延予兆」と整合させる
  5. 返信を待つ間も、確定できる部分は進め、次回報告日を約束する
  6. バッファ不足が原因なら、次案件の 作業日数とバッファ を見直す

FAQ

何日前までに連絡すべき？（目安のみ）

遅れる可能性が見えた時点です。残り3営業日以上あるうちの共有が無難な目安です。当日連絡は最後の手段にしてください。

原因をどこまで書く？

相手の判断に必要な事実だけです。「素材が未着のため着手が遅れた」程度で足りる場合が多いです。個人的な事情の詳細は書かず、影響と次の案に重心を置きます。

進捗連絡（P4）との違いは？

進捗連絡は定期の状況共有、遅延連絡は納期への影響と代替案の提示が主目的です。進捗で「遅延の予兆」が出たら、本記事の型で本格連絡に切り替えます。

謝罪はどの程度書く？

冒頭1行で十分です。長い謝罪より、具体的な次の提案が相手の負担を減らします。
