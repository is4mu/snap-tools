作業日数とバッファの見積もり方

結論

納期は「作業にかかる日数」だけでは足りません。実働日数に、想定外の手戻り用の余白（バッファ）と、休日・相手の確認待ちを足して、初めて提案できる日付になります。感覚で「来週中」と答える前に、3つの数字を分けて書き出す習慣をつけましょう。

実働日数の洗い出し

まず、自分が机に向かう日数を見積もります。工程ごとに分けるとブレが減ります。

  1. ヒアリング・整理（半日〜1日）
  2. 制作・実装の本体（案件の中心）
  3. 自分側の確認・書き出し（忘れがちなので明示）
  4. 修正対応（見積もりで想定した回数分）

「1日＝何時間か」も自分の中で揃えておきます。副業で平日2時間なら、実働1日はカレンダー1日とは一致しません。

バッファの置き方

バッファは「事故りそうなところ」に置きます。正解の％はありません。次の要素があるほど余白を多めに見ます。

  • 初めての相手・初めての業種
  • 素材や原稿が相手支給
  • 社内確認が複数段ある
  • 並行案件が多い

同型案件を繰り返すなら余白は小さくても回ることがあります。見積もりメモに理由を一言残し、見積もり文 の納期と一致させます。

休日・待ち時間の入れ方

カレンダー上の日数と実働日数は別物です。

  • 休日: 自分の休み、祝日、長期休暇
  • 待ち: 素材提供、確認返信、決裁

待ちは実働に含めず、別枠で足すのがおすすめです。「確認に2営業日」と見積もって、返信が遅いときに実働が食い潰されるのを防げます。時給単価の考え方は ざっくり時給の出し方 を参照してください。

提案納期を出す手順

  1. 工程ごとに実働日数を書き出す
  2. リスクに応じてバッファを足す（理由をメモする）
  3. 休日と確認待ちの日数を足す
  4. 着手日（発注・素材受領日）から逆算して日付にする
  5. 見積もり文の納期欄に「〇営業日＋確認待ち想定」と書く

実例（コピペ用・メモ）

【実働】
・ヒアリング整理: 0.5日
・デザイン本体: 4日
・書き出し・最終確認: 0.5日
・修正2回想定: 1日
小計: 6日

【バッファ】初回クライアントのため +1日

【待ち】原稿確認 2営業日、社内決裁 2営業日

【提案】素材受領後、カレンダー上 12営業日前後

失敗例

実働6日だけ見て「来週金曜」と答え、素材が届かず、確認が2往復増え、結局2週間遅れたパターンです。待ちとバッファを入れずに日付を言うと、ほぼ必ず信頼を損ないます。短く見せたい気持ちは分かりますが、あとから伸ばすより、最初に幅を持たせた方が関係は楽です。

計算機で提案日数を出す

数字の足し算は 作業日数・バッファ計算ツール でたたきを出せます。出力は案件の前提と照らして調整してください。

FAQ

バッファはクライアントにどう説明する？

「確認待ちや手戻りを見込んだ余白」と伝えます。％で説明する必要はありません。見積もり文では「ご発注・素材受領後、10営業日前後（確認状況により変動）」のように書けば十分です。

待ち（確認待ち）は実働に含める？

含めない方が安全です。待ちは相手側の事情で伸びやすく、実働に混ぜると納期の責任の境界が曖昧になります。

複数案件並行のときは？

実働日数を「1日あたり何案件に割くか」で割り算します。同じ週にフルで2本は回らない、と分かっているなら、納期を重ねないか、バッファを厚くします。

短納期を求められたときは？

削れるのは範囲か日数かを切り分け、段階納品など代替案を1つ添えます。
